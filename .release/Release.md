- Реализована возможность передачи считанных данных из ФН на анализ в `KassArrayDA`;
- Обновлён формат хранения загруженных данных `.fsd` для возможности обмена с `KassArrayDA`;
- Исправлены неудобства, присутствовавшие в формате сохранения загруженных данных `.csv`;
- Аналитический функционал удалён из `KassArrayFS` (за исключением прямого извлечения сменных итогов и счётчиков ФН) и передан `KassArrayDA`;
- Добавлен контроль номеров смен и ФПО в сохраняемых файлах;
- Реализовано открытие файла через функцию «Открыть с помощью» для уже запущенного экземпляра приложения;
- Снята с поддержки старая версия кэша файлов выгрузок и статусов;
- Сохранение считанных статусов, если оно включено, теперь выполняется только в папку выгрузки дампов ФН и УРМТ (вариант выгрузки в расположение программы больше не используется);
- Скорректирована обработка дампов в базе выгрузок ФН (исключены некорректные пропуски некоторых файлов, исправлены «фантомные» выдачи реквизитов)
