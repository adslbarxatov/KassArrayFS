- Обновлены внутренние сборки приложения;
- Исправлена ошибка формирования файлов `.fnc` для случаев с множественными перерегистрациями в одном ФН с изменением флагов «автономно», «шифрование», «маркировка», а также версии ФФД. Как оказалось, при включённом шифровании `FNArc` просто обнуляет состав тега `106`. В норме его нужно вычитывать командами `0x45` / `0x46`. Однако команды `0x49` / `0x4A` в таких случаях возвращают неправильную длину буфера, что приводит к невозможности корректного формирования тега `106`. ФНС решила вопрос проще: просто не добавлять его в файл выгрузки (шифрование предполагает наличие ОФД – добавляется только тег `107`);
- Реализован точный расчёт числа считываемых страниц при формировании выгрузок .fnc (для шкалы прогресса)
